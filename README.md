# Zina Almokri — Premium Personal Brand Website

## Project
A premium, editorial-grade personal website for **Zina Almokri (زينا المقري)**, a beauty creator who tests cosmetic/beauty products on her skin, presents the results, and shares evaluations through social media.

## Business ambition
The website must feel like a digital property worth **$50,000+** in strategy, design, engineering, content architecture, SEO, performance, and polish.

This is not a generic influencer website. It should position Zina as a credible beauty authority and create a high-value destination for:
- Brand discovery
- Product reviews and testing
- Portfolio/work showcase
- Brand collaborations
- Audience trust
- Organic search acquisition
- Press / professional inquiries

## Core rule
Do not invent biographical facts, audience statistics, awards, brand relationships, product claims, credentials, or testimonials. Use clearly marked placeholders until verified.

## Development workflow
The project is intentionally divided into phases.

1. Product discovery & content intelligence
2. Information architecture
3. Brand / visual direction
4. UX architecture
5. Design system
6. Frontend foundation
7. Signature visual experience
8. Content system
9. SEO foundation
10. Technical SEO
11. Performance / Core Web Vitals
12. Accessibility
13. Analytics / measurement
14. QA / security
15. Search launch
16. Final polish and handover

Claude Code must complete one phase at a time and produce a report before the next phase begins.
