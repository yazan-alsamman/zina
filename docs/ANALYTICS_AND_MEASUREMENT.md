# Analytics & Measurement

## Business events
Track meaningful actions, not everything.

Recommended events:
- `review_view`
- `brand_view`
- `work_view`
- `journal_view`
- `contact_cta_click`
- `contact_form_start`
- `contact_form_submit`
- `social_click`
- `outbound_brand_click`
- `search_use` if internal search exists

## SEO measurement
Connect the production property to:
- Google Search Console
- an analytics platform selected during implementation

Track:
- organic landing pages
- query visibility
- CTR
- indexed pages
- conversions from organic traffic

## Privacy
Analytics must respect applicable privacy requirements and provide appropriate consent behavior where required.

Do not collect unnecessary personal data.

## Conversion funnel
Search/social → landing page → content → trust/proof → work → contact.

The website should make this path obvious without aggressive popups.
