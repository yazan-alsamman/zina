# Project Master Specification

## 1. Vision
Create the definitive digital home of Zina Almokri: sophisticated, memorable, editorial, fast, discoverable, and credible.

The experience should communicate:
**beauty expertise + real product testing + visual storytelling + trust + premium brand collaboration.**

## 2. Primary objectives
- Establish a premium personal brand presence.
- Explain who Zina is and what she does.
- Showcase testing/review work.
- Showcase brands and collaborations.
- Build trust through structured, transparent content.
- Generate collaboration/business inquiries.
- Build long-term organic search visibility.
- Create an owned platform rather than relying exclusively on social media.

## 3. Target audiences
### Audience A — Beauty audience
People researching beauty products, reviews, routines, comparisons, ingredients, results, and recommendations.

### Audience B — Brands / PR / agencies
Companies evaluating Zina for campaigns, product launches, UGC, reviews, ambassador work, events, and other collaborations.

### Audience C — Media / professional network
Journalists, editors, creators, event organizers, and industry professionals.

## 4. Proposed top-level pages
- `/`
- `/about`
- `/reviews`
- `/reviews/[slug]`
- `/brands`
- `/brands/[slug]`
- `/work`
- `/work/[slug]`
- `/journal`
- `/journal/[slug]`
- `/contact`
- `/press` (only if useful after content discovery)
- `/privacy`
- `/terms`
- `/sitemap.xml`
- `/robots.txt`

Do not implement every route blindly. Validate the information architecture during Phase 1.

## 5. Homepage narrative
Recommended narrative sequence:
1. Hero — immediate identity and positioning
2. Proof / credibility layer
3. Featured testing or review
4. Selected brands
5. Editorial storytelling
6. About Zina
7. Social ecosystem
8. Collaboration CTA
9. Premium footer / navigation

The homepage must not become an overloaded portfolio grid.

## 6. Review content model
Every review should be structured so search engines and humans can understand:
- Product
- Brand
- Product category
- Testing context
- What was tested
- Method / experience
- Observations
- Results
- Pros
- Cons
- Who it may suit
- Who may not prefer it
- Final assessment
- Date
- Media
- Disclosure / collaboration status where applicable
- Relevant links

Never fabricate test results.

## 7. Brand relationship model
A brand page may contain:
- Brand name
- Logo
- Description
- Verified relationship type
- Selected work
- Relevant reviews
- Campaigns
- Media
- External official link

A brand must not be described as a client, partner, sponsor, or collaborator unless verified.

## 8. Conversion goals
Primary:
- Collaboration inquiry

Secondary:
- Read a review
- Explore work
- Discover brands
- Follow social channels
- Subscribe/contact if a newsletter is eventually introduced

## 9. Quality bar
The website should feel:
- Luxury
- Editorial
- Modern
- Confident
- Human
- Tactile
- Fast
- Precise

Avoid:
- Generic influencer templates
- Excessive glassmorphism
- Random gradients
- Over-animation
- Fake metrics
- Stock-looking imagery
- SEO keyword stuffing
- Huge unoptimized media
- Walls of text
- Unnecessary 3D that harms usability
