# Phase Plan

## Phase 0 — Project intelligence
Deliver:
- verified facts inventory
- unknowns / placeholders
- audience analysis
- content inventory
- social/channel inventory
- competitive positioning hypotheses
- SEO topic universe
- technical constraints

Gate:
No design implementation until the information architecture and content requirements are understood.

## Phase 1 — Information architecture + content strategy
Deliver:
- final sitemap
- navigation model
- page purpose matrix
- content models
- internal-linking strategy
- conversion paths

## Phase 2 — Brand direction
Deliver:
- visual territory
- typography direction
- color system
- imagery direction
- motion principles
- art direction
- premium design rationale

## Phase 3 — UX architecture
Deliver:
- desktop/mobile flows
- wireframes
- component inventory
- responsive behavior
- accessibility considerations

## Phase 4 — Design system
Deliver:
- tokens
- typography scale
- spacing
- grids
- buttons
- cards
- navigation
- forms
- editorial modules
- media rules
- motion tokens

## Phase 5 — Engineering foundation
Deliver:
- framework/app architecture
- routing
- content architecture
- reusable components
- environment configuration
- linting/testing
- deployment structure

## Phase 6 — Signature experience
Build the highest-value visual moments without sacrificing speed or accessibility.

## Phase 7 — Content implementation
Build reviews, brands, work, journal, about, and contact using reusable structures.

## Phase 8 — SEO
Implement:
- metadata
- canonical URLs
- sitemap
- robots
- structured data
- breadcrumbs
- internal links
- image SEO
- social metadata
- indexability controls

## Phase 9 — Performance
Target excellent Core Web Vitals and fast mobile loading.
Audit:
- LCP
- INP
- CLS
- image weight
- JS
- fonts
- third-party scripts
- animation
- caching

## Phase 10 — Accessibility + quality
Audit keyboard navigation, focus, contrast, semantic HTML, reduced motion, forms, labels, errors, and screen-reader structure.

## Phase 11 — Analytics + conversion
Measure:
- organic landing pages
- review engagement
- brand-page engagement
- contact CTA clicks
- form submissions
- outbound social clicks
- search queries
- indexing coverage

## Phase 12 — Security + production QA
Check:
- dependencies
- secrets
- forms
- spam protection
- headers
- redirects
- 404/500 behavior
- production build
- mobile browsers
- structured data
- sitemap
- robots

## Phase 13 — Search launch
After production:
- verify Search Console
- submit sitemap
- validate canonicalization
- inspect important URLs
- monitor indexing
- establish SEO reporting

## Phase 14 — Final premium polish
Do a final art-direction pass. Fix anything that makes the site feel template-based, unfinished, slow, or inconsistent.

## Phase gate rule
Claude Code must not silently skip a phase. Each phase ends with a report saved under `docs/reports/`.
