# SEO Master Strategy

## Objective
Build Zina Almokri's website as an authoritative, crawlable, structured beauty-content platform capable of earning organic visibility over time.

SEO is a product requirement, not a final checklist.

## 1. Search intent architecture

### Brand intent
Examples to research/validate:
- Zina Almokri
- Zina Almokri beauty
- Zina Almokri reviews
- Zina Almokri makeup
- زينا المقري
- زينا المقري تجميل

Do not assume these exact queries have meaningful search volume. Validate them.

### Product-review intent
Create genuinely useful review pages around products Zina has actually tested.

Potential patterns:
- `[product] review`
- `[product] تجربة`
- `[product] تقييم`
- `[product] قبل وبعد` only when an actual before/after is available
- `[product] مناسب لمن`
- `[product] pros cons`

### Category intent
Potential content clusters:
- makeup reviews
- skincare reviews
- beauty product testing
- foundation reviews
- concealer reviews
- mascara reviews
- lipstick reviews
- skincare routines
- product comparisons

Only publish topics supported by real expertise, real testing, or useful original analysis.

### Commercial / collaboration intent
Build a professional `/work` and `/contact` ecosystem that can be discovered by brands and agencies.

## 2. Topic-cluster architecture

Pillar: **Beauty Reviews**
- Product reviews
- Category reviews
- Comparisons
- Testing methodology
- Frequently asked questions

Pillar: **Brands**
- Brand profiles
- Selected collaborations
- Brand-specific reviews

Pillar: **Beauty Journal**
- Educational articles
- Testing insights
- Product-selection guides
- Editorial stories

Pillar: **About / Authority**
- Who Zina is
- Approach to testing
- Disclosure principles
- Media / press when verified

## 3. On-page SEO requirements
Every indexable editorial page should have:
- unique title
- unique meta description
- one clear H1
- logical H2/H3 hierarchy
- descriptive URL
- canonical
- Open Graph metadata
- relevant internal links
- descriptive image alt text
- author information where appropriate
- publication/update dates where truthful
- structured data where eligible

## 4. Structured data
Evaluate and implement appropriate schema types, such as:
- Person
- WebSite
- WebPage
- BreadcrumbList
- Article
- Review
- Product
- Organization
- ImageObject

Do not add schema merely because it exists. It must accurately describe visible page content and comply with search-engine guidelines.

For reviews, only mark up review information that is actually present and genuinely attributable to Zina.

## 5. Entity / knowledge graph strategy
Build consistent identity signals:
- exact name
- Arabic/Latin name variants
- official website
- official social profiles
- author pages
- consistent profile biography
- image identity
- links between the website and verified social accounts

Create a strong `sameAs` graph only for verified official profiles.

## 6. Internal linking
Every major page should connect to relevant pages.

Example:
Review → Product → Brand → Related Reviews → Journal → About

Avoid orphan pages.

## 7. Image SEO
Beauty is visual, so image SEO is critical:
- modern formats such as WebP/AVIF where supported
- responsive sizes
- width/height attributes
- lazy-load below-the-fold images
- priority loading for true hero/LCP media
- meaningful filenames
- accurate alt text
- captions when useful
- avoid shipping oversized originals

Do not put essential text only inside images.

## 8. Technical SEO
Required checks:
- HTTPS
- one canonical host
- clean redirects
- XML sitemap
- robots.txt
- canonical tags
- 404 handling
- no accidental noindex
- crawlable navigation
- server-rendered/pre-rendered indexable content as appropriate
- stable URLs
- pagination strategy if needed
- language strategy if Arabic + English are both published

## 9. Arabic + English strategy
If both languages are needed, define the architecture before implementation.

Recommended approach to evaluate:
- `/ar/...`
- `/en/...`

Use correct `hreflang` relationships and localized metadata/content.

Do not machine-translate high-value editorial content without human review.

## 10. Content quality
SEO success must come from usefulness, not volume.

High-value review content should provide:
- original observations
- real images
- clear testing context
- balanced assessment
- useful comparisons
- transparency about sponsorship/collaboration
- clear update dates when content changes

Never create hundreds of thin pages solely for keywords.

## 11. E-E-A-T-oriented trust signals
Strengthen:
- clear author identity
- About page
- testing methodology
- disclosure policy
- contact information
- editorial standards
- transparent collaboration disclosures
- original photography/media
- consistent social identity
- factual claims backed by reliable sources when needed

## 12. Search Console launch checklist
Before launch:
- verify property
- validate sitemap
- inspect canonical URLs
- test robots.txt
- validate structured data
- inspect important pages
- confirm mobile usability
- check indexing directives

After launch:
- monitor impressions
- queries
- CTR
- indexed pages
- coverage
- Core Web Vitals
- rich-result eligibility
- pages gaining/losing visibility

## 13. SEO KPIs
Do not promise rankings.

Measure:
- branded impressions
- non-branded impressions
- clicks
- CTR
- indexed quality pages
- organic sessions
- organic engaged sessions
- review-page entrances
- conversion from organic traffic
- referring domains
- brand/entity visibility

## 14. SEO anti-patterns
Never:
- keyword stuff
- hide text
- create doorway pages
- publish fake reviews
- fabricate ratings
- fabricate partnerships
- use misleading structured data
- copy manufacturer descriptions as the main content
- create mass AI pages with no original value
- sacrifice UX for SEO
